文档树 · DocTree

本地阅读器 + 提问树。免费开源，不提供模型服务，需要你自己的 API Key。

完全免费：GitHub Releases · 第三方购买与本项目无关

  1. 打开 DeepSeek 开放平台，用手机号或邮箱注册并登录。
  2. 进入 API Keys 页面，点「创建 API Key」，名字随意。
  3. 复制生成的 sk-...（只显示一次，丢了就重建一个）。
  4. 账户里要有余额：充值页面。新账号一般有赠送额度，够用很久。
  5. 回到 DocTree，打开右上角设置，把 Key 粘进去，保存。
