# DocTree v1.0.4

## 新增：自定义页面配色

工具栏 **◐** 打开配色面板：

- 一个主色派生整套颜色（背景、面板、边框、文字、强调色、状态色）
- 深色 / 浅色两套主题随意切
- 背景渐变（开关 + 角度）
- 面板透明度（60%–100%）
- 6 套预设 + 恢复默认
- 拖动实时生效，设置存在本地，首屏不闪白

派生规则：取主色的色相与饱和度，按固定明度阶梯生成；主色对比度不足时自动调整到 WCAG 4.5:1。

## 代码块对齐 DeepSeek

- 语言标签 + 复制 / 下载
- 语法高亮：深色 One Dark，浅色 One Light（跟随主题自动切换）
- 卡片底色、头部、边框全部由主题令牌驱动

## 界面调整

- 输入框改成悬浮卡片：内容从下方穿过，最后一行留白按卡片高度动态计算，操作按钮不会被挡
- 回答区去掉卡片底色和边框，纯文字排版
- 工具栏图标全部换成 SVG：搜索、旋转、配色、翻页、缩放、树状图、导出
- 滑杆填充跟随数值，到头时填满
- 定位按钮（⌄）自动居中、点击滚到最新提问并高亮

## 修复

- 手机 / 网页端 Markdown 被识别成纯文本（代码块不渲染）
- 定位按钮图标因全局 padding 偏移 4px
