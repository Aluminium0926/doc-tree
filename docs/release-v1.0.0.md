# DocTree v1.0.0

本地文档阅读器 + 锚定原文的追问树。

## 亮点

- **划词提问**：选中文字即挂引用，写不写问题都行，点「发送」才发
- **追问成树**：在回答里继续选中 → 追问，节点锚定原文或上一段回答，可折叠、可导出、可看结构图
- **上下文不跑题**：全文摘要 + 选中处前后文 + 跨页检索 + 祖先链
- **截图提问**：PDF 上框选一块区域直接问（多模态）
- **荧光笔 / 擦除**、Ctrl+F 搜索、页码跳转、旋转、方向键翻页
- **公式渲染**：KaTeX，支持 `$...$` / `$$...$$`
- **模型自选**：任意 OpenAI 兼容端点，也支持本地 Ollama
- **数据全本地**：文档、问答、配置都在 `data/`，不上传第三方

## 下载

- **Windows 便携版**：`DocTree-1.0.0-win32-x64.zip`（约 184 MB）
  - 解压到**纯英文路径**后双击 `DocTree.exe`
  - 首次启动会在 `%APPDATA%\文档树` 建数据目录

## 快速开始

1. 启动后点右上角 ⚙，填 Base URL / API Key / 模型名
2. 导入 PDF、Word、Markdown 或纯文本
3. 选中文字 → 「用这段提问」→ 点发送（留空也行）
4. 在回答里再选中 → 「追问这段」

详细说明见 [使用手册](https://github.com/Aluminium0926/doc-tree/blob/main/docs/使用手册.md)。

## 已知限制

- 扫描版 PDF 无文字层，需用「框选截图」
- 安装路径含中文时 Electron 可能启动失败（`0x80000003`），请用纯英文路径
- 旋转视图下高亮暂不显示
- 一棵树属于一个文档，暂不支持跨文档引用
