# DocTree v1.0.5

四端同步更新。

## 文件列表可清理

- 点 ✕ 现在是「移出列表」：文件、提问树、高亮全部保留
- 列表底部有「已移除（n）」分组，可恢复或彻底删除
- 重新导入同一份文件（按内容 SHA-256 识别）会自动复用原文档，提问树和上下文原样回来
- 移出确认弹窗支持「下次不再提示」，设置里可恢复

## 版本与渠道声明

- 首次启动声明：官方版本永远免费，第三方购买与本项目无关
- 每次启动检查 GitHub Releases 新版本；有新版弹窗提示下载
- 设置里可开「静默」（不检查更新），也能按版本选择「不再提醒」

## 模型接口

- 文本与视觉可分别配置 Base URL / API Key / 模型
- 支持 Anthropic（Claude）原生接口：`x-api-key`、`anthropic-version`、`system`、流式 `content_block_delta`、图片 block
- 接口格式支持自动识别，也可手动选择 OpenAI 兼容 / Anthropic

## 阅读交互

- PDF 页面右键（手机长按）→「讲解本页」，无选中文字时按整页正文提问
- 无极缩放：Ctrl+滚轮、触控板/手机双指捏合、按住 ＋/− 连续缩放，停止后重绘清晰
- 内联代码改等宽 + 淡底无边框；页面菜单阴影改轻并居中
- 工具栏图标全部 SVG；侧栏收起后不占位，展开按钮移到顶部工具栏
