# DocTree Android v1.0.3

## 新增

- 页面配色：主色派生整套颜色，支持深色/浅色、背景渐变、面板透明度
- 代码块：语言标签、复制/下载，浅色主题下自动换浅色语法配色
- 悬浮输入框：内容从卡片下方穿过，底部留白按卡片高度动态计算
- 工具栏图标换成 SVG；定位按钮居中并支持滚动到最新提问

## 修复

- Markdown 文件被当成纯文本解析（代码块不渲染）
- 输入框图标偏移

## 打包

- versionCode 3 / versionName 1.0.3
- minSdk 24 / targetSdk 34
- 本地服务固定端口 47201，数据存 IndexedDB
