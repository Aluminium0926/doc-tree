# DocTree v1.0.2

## 修复

- **文档区滚动条被遮挡**：分栏抓取区原先贴在文档区右缘 10px，正好压住滚动条，拖滚动条会变成拖分栏。现在抓取区整体移入侧栏内侧，文档区边缘完全让开，滚动条可正常拖动。
- **分栏抓取区不再误触**：抓取区在输入区上方自动截断（按输入区实际高度计算），拖动思考强度滑块时不会被抢走事件。
- **思考强度滑块**：热区 4px → 22px，轨道 6px、滑块 15px，更容易点中。
