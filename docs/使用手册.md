# 文档树 · 使用手册

> 一份"边读边问"的本地工具：导入文档 → 划词提问 → 在回答里继续追问，所有问答长成一棵树。

---

## 1. 安装与启动

### 手机 / 平板 / 鸿蒙（最省事）

浏览器打开 **https://aluminium0926.github.io/doc-tree/**，点右上角 ⚙ 填模型配置，菜单里「添加到桌面」。

不需要安装、不需要命令行；离线可用，文档与追问树存在浏览器本地。

### 安卓 App / 鸿蒙 NEXT

下载 `android-v1.0.3` 里的 `DocTree-android.apk`，安装后打开即可（独立运行，不需要电脑）。

鸿蒙 NEXT 自带的**卓易通**可以直接安装这个 APK；不装卓易通则用上面的网页版。详见 [安卓与鸿蒙](安卓与鸿蒙.md)。

### 桌面版

下载 `DocTree-1.0.4-win32-x64.zip`，解压后**双击 `start-doctree.vbs`**（不是 DocTree.exe）。

- 解压到纯英文路径：直接在原地运行
- 解压到含中文的路径：启动器会先把程序复制到 `%LOCALAPPDATA%\Programs\DocTree`，再从那里启动，并在桌面创建「文档树」快捷方式

> 为什么要这样：Electron 在某些含中文的路径下会一启动就崩（`0x80000003`），日志都来不及写。启动器负责把运行路径换成纯英文，你解压到哪都行。

数据默认在 `%APPDATA%\文档树`，首次启动会把包内 `data` 复制过去。

### macOS

- 网页版：Safari / Chrome 打开 https://aluminium0926.github.io/doc-tree/ ，Chrome 可「安装应用」
- 现成安装包：[mac-arm64-v1.0.1](https://github.com/Aluminium0926/doc-tree/releases/tag/mac-arm64-v1.0.1)（Apple Silicon）或 [mac-x64-v1.0.1](https://github.com/Aluminium0926/doc-tree/releases/tag/mac-x64-v1.0.1)（Intel），解压后双击「首次打开.command」
- 源码：`npm install && npm start`，或 `npm run app` 直接开窗口
- 自己构建：`bash scripts/build-macos.sh arm64`，或跑 GitHub Actions 的 `build-mac-cross` 工作流

> 包未签名未公证，「首次打开.command」会自动去隔离并做 ad-hoc 签名（Apple Silicon 必需）。
- 数据目录：`~/Library/Application Support/文档树`，菜单里有 Cmd+C/V/Z

### 源码运行（开发/自用）

```bash
npm install
npm start
```

打开 http://127.0.0.1:4317 。想让同局域网手机访问：`HOST=0.0.0.0 npm start`。

## 2. 配置模型

点右上角 **⚙**：

| 字段 | 说明 | 示例 |
|---|---|---|
| Base URL | OpenAI 兼容端点（含 `/v1`） | `https://api.deepseek.com/v1` |
| API Key | 你自己的 key | `sk-...` |
| 对话模型 | 主模型 | `deepseek-flash` |
| 视觉模型 | 截图提问用，可留空 | `deepseek-flash` |

也支持本地模型：`baseUrl` 填 `http://127.0.0.1:11434/v1`，模型名填本地模型即可。

**思考强度**：输入框左下角滑块，三档「轻 / 标准 / 深度」，对应 `low / high / max`。实测长文档下「轻」最快，「深度」思考量最大但不一定更慢。

## 3. 阅读

- **PDF**：按页原版式渲染，缩放、旋转、页码跳转都在顶部工具条
- **Word / Markdown / 纯文本**：重排成白纸阅读
- 左侧文档库支持多份文档，每份有独立的追问树
- 左栏可收起（左上角 « 或 `Ctrl+B`），左右边界可拖动调宽

## 4. 提问与追问（核心）

### 划词提问

1. 在正文里选中一段文字 → 浮出「**用这段提问**」
2. 点它，引用会挂到右下角输入框上方
3. 写不写问题都行 → 点 **发送**
   - 留空时用默认问法「请讲解这段内容」

### 追问

1. 在**回答**里再选中一段 → 浮出「**追问这段**」
2. 同样点发送 → 新节点挂在刚才那条回答下面，形成分支

### 同一段多次追问

对同一段文字反复追问，会生成同一父节点下的多个分支，互不覆盖。

### 截图提问

点「框选截图」→ 在 PDF 页面上拖一块 → 松手后截图挂到输入框 → 点发送。

适合扫描件、图表、公式截图。

## 5. 追问树

右侧就是树，缩进 + 折叠。

- 节点上悬停出现「追问 / 复制 / 删除」
- 删除会连同子分支一起删
- 顶部 **⌗** 打开结构图：滚轮缩放、拖动平移、点节点跳回列表
- 顶部 **⭳** 把整棵树导出 Markdown

树的上下文是怎么送的：全文摘要 + 选中处前后各 1200 字 + 跨页检索的 3 段 + 祖先链（每层压缩）。所以追问深了也不会爆 token。

## 6. 荧光笔 / 搜索 / 快捷键

| 功能 | 用法 |
|---|---|
| 荧光笔 | 点「荧光笔」→ 选文字即高亮，支持黄/绿/粉；Esc 退出 |
| 擦除 | 点「擦除」→ 点任意高亮删除；Esc 退出 |
| 搜索 | 点 ⌕ 或 `Ctrl+F`，Enter / ↓ 下一个，Shift+Enter / ↑ 上一个，Esc 关闭 |
| 翻页 | ← / →（瞬切） |
| 滚动 | ↑ / ↓ 90px，PgUp / PgDn 一屏，Home / End 首尾 |
| 收起左栏 | Ctrl+B |

## 7. 数据与备份

桌面 / 服务端：

```
data/config.json     模型配置（含明文 key）
data/docs/*.json     文档文本 + 摘要 + 高亮
data/trees/*.json    追问树
data/files/*         原始文件
```

- 备份：复制 `data/` 目录
- 桌面版：`%APPDATA%\文档树`
- **key 是明文**，别把 data 目录传给公开仓库

手机 / 网页版：

- 文档、追问树、原文件存在浏览器 **IndexedDB**
- 模型配置存在 **localStorage**
- 换浏览器、清站点数据会丢；需要留存时用「导出 Markdown」

## 8. 常见问题

**Q：划词没反应？**
扫描版 PDF 没有文字层，选不中。用「框选截图」。

**Q：公式没渲染？**
用 `$...$` 或 `$$...$$` 包裹；`\(...\)` 也兼容。渲染失败会退回显示源码。

**Q：回答很慢？**
首字延迟主要取决于模型和上下文长度。把思考强度调到「轻」通常快一倍。

**Q：页面变白？**
切后台/休眠后浏览器可能回收画布。切回来会自动重绘；如果没恢复，滚动一下或刷新。

**Q：桌面版双击没反应？**
1. 确认路径是纯英文
2. 看 `%APPDATA%\文档树\desktop.log` 最后几行
3. 试「兼容模式」快捷方式（`--disable-gpu`）

**Q：端口冲突？**
`PORT=4400 npm start` 换端口。

## 9. 自建/二次开发

- 回答风格、是否生成应试内容：改 `lib/context.mjs` 里的 system prompt
- 换模型：设置面板，或 `data/config.json`
- 前端无构建步骤，改完刷新即可
- 接口：`/api/state`、`/api/import`、`/api/ask`（SSE）、`/api/highlights`
