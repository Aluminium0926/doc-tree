# 宣传素材

## 一句话

**把"划词提问"和"追问"连成一棵树——所有问答都锚定在原文上，读到哪里，想到哪里。**

## 三句话

读论文、读讲义、读合同，我们真正卡住的往往不是"这段在说什么"，而是"这段和前面那段什么关系""作者为什么这么写"。

聊天式 PDF 工具能回答，但对话一长就散了：你忘了刚才问的是哪一段，也看不出哪次追问是从哪句话长出来的。

文档树把每次提问记成一个节点，锚定原文（或上一段回答），可以无限分叉、折叠、导出——**你读过的每一处疑问，都留在它该在的位置上**。

## 痛点 → 解法

| 痛点 | 文档树的做法 |
|---|---|
| 选中一段问 AI，回答不错但下一问就丢了上下文 | 每个节点带祖先链，追问自然承接 |
| 对话越滚越长，找不到刚才问的是哪段 | 侧栏是树，节点上直接显示引用片段和页码 |
| 通用聊天模型泛泛而谈 | 送全文摘要 + 跨页检索段落 + 选中处上下文，回答贴着文档 |
| 文档、问答上传到别人服务器 | 全部本地：文档、树、配置都在 `data/`，只调用你自己配的模型端点 |
| 想回头复习，聊天记录翻不动 | 整棵树导出 Markdown，或看结构图 |

## 和常见工具的区别

- **ChatPDF / 各类"和 PDF 聊天"**：单线程对话 + 全文问答，没有"锚定某段 + 分支追问"的结构
- **NotebookLM**：强在总结和播客，交互仍是问答，不是"读到哪里问到哪里"
- **阅读器插件**：划词翻译/解释强，但没有可持续的追问记录
- **文档树**：把"阅读位置"和"问答历史"绑在一起，且完全本地

## 适合谁

- 读论文/教材的学生和研究者（尤其需要反复对照前后文）
- 看合同、标书、报告的人（逐条确认 + 追问依据）
- 需要把"读文档时的思考过程"沉淀下来的人（导出即笔记）
- 对隐私敏感、想接本地模型的人（Ollama 直接可用）

## 功能清单（发版用）

- PDF 原版式渲染 + 文字层划词；Word/Markdown/纯文本重排
- 划词提问、回答内再划词追问，树状分支
- 全文摘要 + 跨页检索 + 祖先链上下文
- 截图提问（多模态）
- 荧光笔三色 + 擦除
- 文档内搜索、页码跳转、旋转、缩放、方向键翻页
- 公式渲染（KaTeX）
- 追问树结构图、Markdown 导出
- 任意 OpenAI 兼容端点 / 本地 Ollama
- 桌面版（Electron，便携目录）
- 数据全本地，无云端

## 短文案（可直接发）

**通用版**

> 做了个本地文档阅读器：选中一段就能问，回答里还能继续选中追问，所有问答长成一棵锚定原文的树——读论文时特别顺手。支持 PDF/Word/Markdown，可接 DeepSeek 或本地 Ollama，数据不出本机。开源 MIT。

**V2EX / 少数派风格**

> 平时读论文最大的问题是"这一段和前面什么关系"，ChatGPT 能答，但聊完就找不到了。于是写了个工具：每次提问是一个节点，锚定在原文那一段上，追问挂在回答下面，最后能导出整棵树。全本地，模型自己配。MIT。

**小红书/微博**

> 读论文神器：划词提问 + 回答里继续追问，问题会像树枝一样长在原文旁边🌿 支持 PDF/Word，能接 DeepSeek，也能用本地模型，数据都在自己电脑里。开源免费。
