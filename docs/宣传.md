# 宣传素材

## 主标语

**选中就问，问过还在。**

副标：

> 上课听不懂的那句、论文读不懂的那段，选中就能问：不截图、不复制、不切屏，答案贴在那行字旁边；下次翻回这一页，问过的还在。

备选（不同气质，按需取用）：

- **想弄懂这一页，不用离开这一页。** —— 品牌向，文艺，适合当 logo 区标语
- **老师翻页之前，问完这一句。** —— 上课场景专用，时间压力感最强

## GitHub About 一行

> 选中就问，问过还在。文档里划一下就能问 AI，不截图、不切屏；问题锚在原文上，翻回那一页还在。本地运行。

（在仓库 Settings → General 的 Description 里填，记得同步 Topics：local-first / ai / pdf）

## 定位：用户的心理账

上课听不懂的那一刻，用户心里算的是这笔账：

> 问一次 = 截图 + 切窗 + 粘贴 + 打字说明 + 等回答 + 切回来跟丢课堂进度。
> 这笔账大多数时候算下来是两个字：**算了**。

所以产品承诺不是“操作更快”，而是：

1. 问一次 ≈ 划一下 —— “想问”不必再变成“算了”
2. 问过的东西留在原处 —— 不必再变成“找不回”

## 动作对比表

| 以前问 AI 要做的事 | 文档树 |
|---|---|
| 截图 / 复制粘贴那段话 | 划一下，自动带过去 |
| 打一句“帮我解释这段” | 可以一个字都不打 |
| 切到浏览器，等答案，切回来 | 答案就贴在那一页旁边 |
| 追问再截一次图 | 回答里再划一下，上下文自己带过去 |
| 想回头找，翻聊天记录 | 问题就长在原文那一页上 |

## 和常见工具的区别

- **ChatPDF / 各类“和 PDF 聊天”**：单线程对话 + 全文问答，没有“锚定某段 + 分支追问”的结构
- **NotebookLM**：强在总结和播客，交互仍是问答，不是“读到哪里问到哪里”
- **划词翻译 / 解释插件**：选中就能查，但没有可持续的追问记录，问过就散
- **文档树**：把“问”压到一次划选，并把问答钉在原文位置，完全本地

## 适合谁

- 上课听不懂、跟不上节奏，想当场问又怕折腾的学生
- 读论文 / 教材的研究者（需要反复对照前后文、追问依据）
- 看合同、标书、报告的人（逐条确认 + 追问依据）
- 想接本地模型、数据不出本机的人（Ollama 直接可用）

## 功能清单（发版用）

- PDF 原版式渲染 + 文字层划词；Word / Markdown / 纯文本重排
- 划词提问、回答内再划词追问，树状分支
- 留空直接发送（默认问法），连问题都不用打
- 全文摘要 + 跨页检索 + 祖先链上下文
- 截图提问（多模态）
- 荧光笔三色 + 擦除
- 文档内搜索、页码跳转、旋转、缩放、方向键翻页
- 公式渲染（KaTeX）
- 追问树结构图、Markdown 导出
- 任意 OpenAI 兼容端点 / 本地 Ollama
- 桌面版（Electron，便携目录）
- 数据全本地，无云端

## 短文案（可直接发）

**V2EX / 少数派**

> 上课或读论文时总有一个反复出现的瞬间：一句话没看懂。想问 AI，先截图、切到浏览器、粘贴、再打一句“帮我解释这段”——一套下来，老师已经翻页了。于是大多数时候，我选择算了。
>
> 后来写了个小工具。它是个本地文档阅读器（PDF / Word / Markdown），AI 在同一个窗口里：选中 → 点「用这段提问」→ 回车。不写问题也行，它自己带上你选中的位置、前后文和全文检索到的相关段落。
>
> 追问同样是一划：在回答里继续选中，它会带上“引用 + 问题 + 上轮回答”的祖先链，不跑题。每个问题都锚在原文第几页、哪一句，长成一棵树，而不是滚不到头的聊天记录。下次翻回那一页，问过的都还在。
>
> 数据全本地，端点自己配（DeepSeek / OpenAI / Ollama）。MIT，Windows 便携版解压即用。

**小红书 / 微博**

> 上课最难受的不是听不懂，是想问又算了😮‍💨
> 截图 → 切窗口 → 粘贴 → 打字“解释下这段” → 答案回来，老师翻页了
>
> 自己写了个工具，把这串动作变成一个选中：
> 选中那句话 → 点一下 → 回车，答案就贴在旁边，连问题都不用打
> 想追问就在回答里再划一下，问题像树枝一样长在那句话旁边🌿
> 下次翻回这一页，之前问过的都还在，不用翻聊天记录
> PDF / Word / MD，可接 DeepSeek 或本地模型，文件不出电脑，开源免费

**朋友圈 / 一句话**

> 上课没听懂的那句，选中就能问——不截图、不复制、不切屏；问过的都留在那一页，翻回去还在。

> 注意：口号是承诺，具体动作按真实的“选中 → 点一下 → 回车”写，别夸大成一步。若以后浮层加了「直接问」按钮，“选中就问”就能字面成立。
