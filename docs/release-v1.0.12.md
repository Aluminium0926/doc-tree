# DocTree v1.0.12

四端同步更新。这一版主要修显示、搜索和 PPT 支持。

## PPT / PPTX

- 桌面端导入 `.ppt` / `.pptx` 时自动调用本机 PowerPoint 转成 PDF，保留版式、图片和图表
- 转换后的幻灯片按 PDF 页工作：搜索、提问、页面读图都能用
- 没装 PowerPoint 或转换失败：`.pptx` 退回纯文字提取，`.ppt` 提示另存为 PDF
- 手机/网页端仍只支持 PPTX 文字提取

## 化学式

- 加载 KaTeX mhchem 扩展，`\ce{...}`、`\pu{...}` 可以正常渲染
- 模型没写 `$...$` 的裸 `\ce{}` 会自动补成行内公式
- 支持嵌套花括号

## 窄窗口与工具栏

- 侧栏在窄窗口下可以正常收起/展开，不再被隐藏
- 工具栏按**文档区实际宽度**换行，不再按窗口宽度判断
- 输入框变窄时优先保留「指令 / 停止 / 发送」，状态文字不再被挤成一条线
- 右侧追问栏窄窗口下限制占比，文档区不会被压到 400px 以下

## 搜索

- 一页内所有命中都会高亮，当前跳转项用橙色强调

## 稳定性

- 数据加载失败自动重试 6 次，不再把失败显示成空文档库
- 导入前校验格式白名单，非法文件不再当文本解析导致卡死
- 超过 150MB 的文件直接拒绝
- 缩放查看时恢复完整屏幕像素比（≤120% 用 2x，更高限制 1.5x），缩小不再发虚
- 请求超时、重试、停止/继续生成等沿用 v1.0.11
