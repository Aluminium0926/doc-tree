# DocTree v1.0.10

四端同步更新。这一版主要是“把日常用起来别扭的地方补齐”。

## 文档组

- 组名双击重命名
- 组行 `＋` 可把其他文档移入（含其他组里的，原组自动收敛）
- 组内文档右侧「移出」，提问树会复制给该文档
- 成员少于 2 份时组自动解散，树保留
- 侧栏「已移除（n）」可折叠，状态记忆

## 指令模式

- 提问框左侧「指令」按钮：输入什么就发什么，用于修改回答方式
- 指令存到文档，之后每次提问自动附加（最多 20 条）
- 不计入提问树；标题下方显示 `指令 N`
- 点 `指令 N` 可查看列表、单条删除或清空全部
- 指令模式下发送「清除指令」也可以清空

## 停止与继续

- 生成中可以点停止按钮
- 停止后回答保留，节点出现「继续」，从断点续写，不重复已有内容
- 修了客户端中止信号传不到服务端的问题

## 模型用量

- 每个节点记录 input / output / cache 命中
- 节点底部显示 `输入 1.2k · 缓存 900 · 输出 80`
- 设置里「查看模型用量」：总 tokens、缓存命中率、最近 14 天、按文档统计
- 同时兼容 OpenAI 兼容端点与 Anthropic 的 usage 字段

## 稳定性与成本

- 429 / 5xx / 网络错误自动重试（最多 2 次，优先遵守 Retry-After）
- 120 秒请求超时
- 工具调用时界面显示「正在读第 42 页…」「正在检索…」
- 新增 `read_pages(from,to)` 跨页读取工具
- 句子级分块，检索命中附前后页开头
- 提示词结构优化：静态 system + 文档/摘要/指令前置 + 模式与检索后置
- Anthropic 增加 `cache_control`（system、tools、稳定段）

## 界面

- Ctrl / Cmd `+` `-` `0` 缩放页面
- 截图缩略图限宽、占满整行、裁右
- 停止按钮换成居中的 SVG 方块，尺寸加大
- 操作提示改成主题色，不再像报错

## 修复

- DeepSeek 的 `<|DSML|invoke>` 工具标记漏出（全角/单竖线也能识别）
- 追问回答时锚点变成第 1 页
- 未选中文字时默认锚定第 1 页
- PDF 快速滚动偶发空白页（自动补画）
- 提问框偶发无法输入（焦点兜底）
- 服务端版本过期提示挡住输入框
- Markdown 渲染 XSS、Android 代理缺 Anthropic 认证头
