# DocTree v1.0.11

四端同步更新。这一版主要补“模型看不见图”和移动端与桌面端的能力差距。

## 页面读图

- 对 PDF 提问时自动附带当前页截图，模型可以看图里的图表、公式和排版
- 桌面端由服务端把页面渲染成 PNG；手机/网页端用浏览器 PDF.js 渲染，不依赖服务端
- `read_page(page)` 工具现在返回“该页文字 + 该页截图”，读别的页也能看到图
- 带图时自动切换到设置里的视觉模型
- 手动框选截图仍然优先于整页图

## 移动端补齐

- 停止生成：中止信号真正传到生成端，不再只是界面停下
- 继续生成：带当前页图续写
- 请求超时 120 秒
- 429 / 5xx / 网络错误重试（最多 2 次）
- PWA 外壳改网络优先，发版后不会再被旧缓存卡住
- 框选模式加 `touch-action: none`，拖动不会带着页面滚

## 性能

- 远离视口的 PDF 画布自动释放，滚几十页内存不再线性上涨
- 渲染像素比上限从 2 降到 1.5
- 缩放重排不再重画已释放的远处页面

## 修复

- `visionFormat=auto` 被当成显式格式，导致带图请求走错协议
- Anthropic 工具循环使用非法的 `role: tool`，改为标准 `tool_result`
- Anthropic 工具结果图片、用户消息图片透传
- 手机上长按拖动导致框选区域与页面滚动冲突

## 说明

新增原生依赖 `@napi-rs/canvas` 与 `pdf-to-img`，用于服务端把 PDF 页渲染成图片。Windows 包已内置；macOS 包在对应架构上安装对应二进制。
